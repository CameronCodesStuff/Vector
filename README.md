# Vector

A multi-purpose cybersecurity, automation, networking, and research toolkit built in Python.

> ⚠️ Disclaimer
>
> This repository contains security-related tools intended for educational purposes, security research, authorized testing, and learning. Users are responsible for complying with all applicable laws and obtaining proper authorization before using any functionality.

---

## Features

### 🔍 Reconnaissance & Information Gathering

- API Endpoint Mapper
  - Discover and analyze web API endpoints.
- Advanced Web Scraper
  - Collect and process data from websites.
- Network Analysis Tools
  - Gather network information and connectivity details.
- Phone Information Lookup
  - Analyze publicly available phone-related information.
- Browser Analysis Utilities
  - Browser interaction and data collection tools.

## Installation

### Requirements

- Python 3.10+
- Windows Operating System
- Required Python packages

### Setup

```bash
git clone https://github.com/USERNAME/Vector.git
cd Vector
```

Run:

```bat
installrequirments.bat
```

Or install dependencies manually:

```bash
pip install -r requirements.txt
```

---

## Usage

Launch the main interface:

```bat
Vector.bat
```

Or run individual modules:

```bash
python module_name.py
```

Example:

```bash
python network.py
```
